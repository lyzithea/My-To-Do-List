# My To Do List

- A simple and customizable To-Do List web application built with HTML, CSS, and JavaScript.

- This project was created to practice JavaScript fundamentals, DOM manipulation, and working with localStorage. 


# Features

- Add tasks: Create new tasks using the input field, add them with the add button or with enter.

- Complete tasks: Mark tasks as completed using checkboxes.

- Delete tasks: Remove tasks from the list.

- Animations: Smooth animations when adding and deleting tasks.

- Local storage: Tasks and their completion status are saved automatically.

- Color themes: Choose between purple, blue, and green.

- Saved preferences: The selected color theme remains active after refreshing the page.


# Technologies Used

- HTML5 Structure of the application

- CSS3 Styling, animations, gradients, and color themes

- JavaScript Application logic, DOM manipulation, and event handling

- localStorage Saving tasks and theme preferences in the browser
